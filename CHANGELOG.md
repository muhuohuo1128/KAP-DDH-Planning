# Change log

## 1.0.0 — 2026-10-05

- Initial public release of the KAP-DDH preoperative planning module.
- Added the geometric planning engine, English graphical interface and portable configuration.
- Added documentation for inputs, outputs and study-specific constraint integration.
- Added a fully synthetic fixed-constraint example with reference outputs and verification utilities.
- Added software validation notes and reproducibility checks for the public release.
- Released the public source under GPL-3.0-only.
